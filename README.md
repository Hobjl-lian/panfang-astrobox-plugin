# 盘坊视频表盘

AstroBox 插件。在插件里点「开始制作」会打开盘坊的制作页：选视频、截取片段、生成表盘，完成后成品自动进入 AstroBox 安装队列。

桌面版在内置浏览器里制作；手机版会用系统浏览器打开制作页（内置浏览器的文件选择不可用），做完后回到插件页会自动下载；「最近制作」里也可以手动安装。

## 要求

- AstroBox 2.2.6 或更高版本（api_level 4）
- 已连接支持的手表，画布以制作页显示的模板为准
- 爱发电账号

## 权限

- `browser`：桌面版打开制作页并拦截完成回跳
- `device`：读取当前连接的手表
- `queue`：把成品加入 AstroBox 安装队列
- `register_deeplink_action`：手机版接收制作页做完后的回跳（失败时仍可用「继续安装」）

## 隐私

视频只在手机本地解码和抽帧，不上传原视频。上传到盘坊服务器的只有抽帧图片包，用于生成表盘；成品在插件沙箱内解密后交给安装队列，旧成品保留 24 小时后清理。

隐私政策：https://api.hobjl-shop.top/privacy
